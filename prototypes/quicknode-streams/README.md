# QuickNode Streams

Reserved for the QuickNode prototype; the case study keeps its current placeholder until a runtime is implemented.

Follow [the shared prototype structure](../README.md): `config.ts`, an interactive entry, `components/`, `state/`, `data/`, `design-system/`, `preview/`, and `styles/prototype.css`. Build QuickNode's own components and tokens here. Reuse the shared viewer and loading protocol, rather than Hyper's meeting components. Add its thin route and preview registration when the experience is ready.
